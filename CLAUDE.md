# Baune8D

The profile README for https://github.com/Baune8D. GitHub only shows `README.md` on the profile.

## Workflow

- Conventional commits (`feat:`, `fix:`, `chore(deps):`, `ci:`, `build:`, `docs:`), one commit per concern, directly on `main`.
- Only push, tag, publish or edit GitHub releases when asked.
- Commit messages must be accurate. If one turns out to be wrong before it is pushed, reword it (replay the commits and check that the tree is unchanged). Never rewrite pushed history.

## Content

- The project list uses each repository's GitHub description, shortened where needed, and a version badge for the published packages. Update it when a repository is added, renamed or archived, or its description changes. The resumé site (baune8d.github.io) has a project list in `_config.yml` too; keep both in step.
- Use images from GitHub or shields.io only. The earlier stats cards came from the public github-readme-stats instance and broke when it went offline.
